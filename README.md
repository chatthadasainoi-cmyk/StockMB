# StockMB: Stock Manager Basic System

A Windows desktop app that replaces hand-written notes and Excel for a small shop: sales at the counter, stock in and out, profit reports, and staff accounts with role-based access.

**Live demo (web, sample data):** https://chatthadasainoi-cmyk.github.io/portfolio/demo/stockmb/ · login is pre-filled (`demo` / `demo1234`)

![Dashboard](https://chatthadasainoi-cmyk.github.io/portfolio/img/sm-dash.jpg)

## Features
- **Dashboard:** income against import cost and salaries, by day, month or year
- **Product sales:** cart, checkout, every sale recorded with seller and time
- **Product management:** add, edit, restock, delete, or bulk-import from Excel
- **Reports:** sales and import history, per-product statistics, filters
- **Employees:** staff records and roles; staff are locked out of admin pages

## Tech stack
Electron · SQLite · JavaScript · HTML/CSS · Chart.js

## Run locally
```bash
npm install
npm start
```
